# Git_Practice

## About
This repository is created for learning and practising Git and GitHub. It serves as a personal workspace to understand version control, explore Git commands, and gain hands-on experience with managing projects using Git and GitHub.

## Objectives
- Understand the fundamentals of Git and version control.
- Learn how to initialize and manage Git repositories.
- Practise staging, committing, and tracking changes.
- Understand branching and merging.
- Learn how to resolve merge conflicts.
- Work with remote repositories on GitHub.
- Practise pushing and pulling code between local and remote repositories.
- Understand how to collaborate on projects using GitHub.

## Topics Covered
- Git installation and configuration
- Repository initialization (`git init`)
- Checking repository status (`git status`)
- Tracking changes (`git add`)
- Committing changes (`git commit`)
- Viewing commit history (`git log`)
- Working with branches (`git branch`)
- Switching branches (`git switch`)
- Merging branches (`git merge`)
- Connecting local and remote repositories (`git remote`)
- Pushing changes (`git push`)
- Pulling changes (`git pull`)
- Cloning repositories (`git clone`)
- Creating and managing `.gitignore` files
- Understanding merge conflicts

## Purpose
The main purpose of this repository is to build practical Git and GitHub skills through consistent practice. It will also serve as a reference for Git commands and concepts that I can use in future software development projects.
